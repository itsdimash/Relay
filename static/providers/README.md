# Provider logos (optional)

Put the official logo files here and Relay shows them in the agent avatars instead of the letters "Cl" and "Cx":

- `claude.svg` (or `claude.png`) for Claude
- `openai.svg` (or `openai.png`) for Codex

Get them from each company's brand page and follow its usage guidelines. They are not drawn or generated by Relay.
Use a simple, single-colour mark on a transparent background. Without these files nothing changes.
