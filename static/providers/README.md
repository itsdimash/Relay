# Provider logos

Relay shows these files in the agent avatars (Team cards and activity feed):

- `claude.png` (or `claude.svg`) for Claude
- `openai.png` (or `openai.svg`) for Codex

To change a logo, replace the file here. If both an `.svg` and a `.png` exist, the `.svg` is used. If a file is missing, the avatar shows the letters "Cl" or "Cx" instead.

The marks belong to Anthropic and OpenAI; follow each company's brand guidelines when using them.
Use a square image with a transparent background (the Claude mark is a full badge, the OpenAI mark is a single-colour glyph).
